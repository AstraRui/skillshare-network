# skillshare-network
SkillShare Network — платформа немонетарного обмена компетенциями. Система автоматизирует бартер интеллектуальных услуг через интеллектуальный алгоритм матчинга. Включает REST API для управления профилями навыков, real-time чат на WebSockets и систему поиска многосторонних цепочек обмена.
