
 SkillShare Network

SkillShare Network — платформа для взаимного обмена навыками.

##  Описание

SkillShare Network — это веб-приложение, где пользователи могут публиковать объявления о том, чему они могут научить (предлагаемый навык) и что хотят получить взамен (желаемый навык). Другие пользователи откликаются на объявления, и при взаимном интересе система создаёт «сделку». Внутри сделки открывается чат, где участники договариваются о деталях и проводят обмен. После завершения сделки каждый оставляет отзыв, формируя рейтинг доверия.

Проект решает проблему поиска единомышленников для бесплатного или взаимообразного обмена знаниями, умениями и услугами.

## Возможности 

- Публикация объявлений  
  Пользователь создаёт объявление: указывает заголовок, описание, краткое содержание «что предлагаю» и «что хочу получить». Объявление может быть в черновике, опубликовано или архивировано.

- Отклики на объявления  
  Заинтересованный пользователь отправляет отклик с сообщением. Автор объявления может принять или отклонить отклик.

- Сделки (обмены)  
  После принятия отклика создаётся сделка. Жизненный цикл сделки:  
  discussion (обсуждение) → active (активный обмен) → completed (завершена) / cancelled (отменена).

- Встроенный чат  
  Каждая сделка получает собственный чат. Участники могут обмениваться сообщениями, прикреплять медиафайлы. После завершения сделки чат становится доступен только для чтения (архив).

- Оценки и рейтинг  
  По завершении сделки каждый участник оставляет отзыв (оценка от 1 до 5). Средний рейтинг пользователя отображается в профиле и влияет на матчмейкинг.

- Матчмейкинг (автоматические рекомендации)  
  Система анализирует предлагаемые/желаемые навыки, уровни, активность и рейтинг, предлагая пользователям наиболее подходящие пары для обмена.

- Роли пользователей  
  user (обычный), admin (модерация объявлений, отзывов, сделок).

- Мягкое удаление и модерация  
  Объявления, отзывы, сделки можно пометить как удалённые (без физического удаления). Модераторы могут скрывать неподобающий контент.
